## STEP 1 — Install and activate the plugin (0:25–1:00)

**VOICEOVER:**
"First, let's install the plugin. From your WordPress dashboard, go to **Plugins**, then click **Add New**. In the search box on the top right, type 'Video Player Block'. When it appears, click **Install Now**, and after a moment click **Activate**. That's all there is to it — no setup wizard and no account needed. The block is ready to use right away."

**ON SCREEN:** Dashboard → Plugins → Add New → type "Video Player Block" in search → Install Now → Activate.

**TEXT:** Step badge: **"Step 1: Install & Activate"**

## STEP 2 — Add the block to a page (1:00–1:35)

**VOICEOVER:**
"Now let's add it to a page. Open any page or post — I'll create a new one. Click the **plus** icon to add a block, and in the search box, type 'Video Player'. Click the block to insert it. You'll see a placeholder that says 'Upload or paste a video URL to get started.' This is where we choose our video."

**ON SCREEN:** Pages → Add New → click + inserter → search "Video Player" → click block → placeholder appears.

**TEXT:** Step badge: **"Step 2: Add the Block"**

## STEP 3 — Add your video (self-hosted or YouTube/Vimeo) (1:35–2:20)

**VOICEOVER:**
"You have two easy ways to add a video. Option one: click to **upload** a video file, or select one from your Media Library — this works for MP4, WebM, and OGG files. Option two, and this is really handy: just **paste a YouTube or Vimeo link**, and the plugin automatically detects it and loads it right inside the same good-looking player. I'll upload an MP4 first… and there's our player with its styled controls. And just to show you — if I paste a YouTube URL instead, it loads that too, in the exact same player skin."

**ON SCREEN:** Upload/select an MP4 → player appears. Then briefly demo pasting a YouTube URL to show it loads in the same player.

## STEP 4 — Adjust the Settings tab (2:20–3:10)

**VOICEOVER:**
"With the block selected, look at the settings panel on the right. There are three tabs: **Settings**, **Controls**, and **Style**. Let's start with **Settings**. Here you can set a **poster image** — the thumbnail shown before the video plays. Below that you'll find playback options: **Autoplay** — just note that browsers usually need the video muted for autoplay to work — **Loop** to replay automatically, and **Reset on End**. You can also **Start Muted**, **Auto-Hide the Controls** while playing, and turn on **Lazy Load**, which waits to load the player until the visitor scrolls to it — that keeps your page nice and fast. And for self-hosted videos, you can even add **captions and subtitles**."

**ON SCREEN:** Open Settings tab → set a poster → toggle Autoplay, Loop, Reset on End, Start Muted, Auto-Hide Controls, Lazy Load → open the Captions panel briefly.

**TEXT:** Step badge: **"Step 3: Settings"** · small note near Autoplay: *"Tip: Autoplay usually needs Muted ON"*

## STEP 8 — Shortcode & reusable player

**VOICEOVER:**
"The Video Player Block also comes with a handy **shortcode** feature — perfect when you want to reuse the same player in several places, or add a video where blocks aren't available, like widgets or older themes. In your admin menu you'll find a dedicated **Video Player** section. Click **Add New** to create a reusable player — notice it opens with a Video Player Block already in place. I'll paste a video and publish it, exactly like before. Now open the **Video Player list**: in the **Shortcode** column, each player has its own shortcode like `[video_player id=123]`. Click to copy it, then paste it into any page, post, or widget to display that exact player."

**ON SCREEN:** Admin menu → **Video Player → Add New** → block already present → paste video URL → Apply → Publish. Then **Video Player → All items** → highlight the **Shortcode** column → click the shortcode field to copy → (optional) paste `[video_player id=X]` into a widget/classic block.

**TEXT:** Step badge: **"Step 8: Shortcode"** · Callout: *"Reuse anywhere with `[video_player id=X]`"*

## Accurate feature reference (for on-screen text)

**Free version**
- HTML5 player for self-hosted **MP4, WebM, OGG**
- Native **YouTube & Vimeo** support in the same player skin
- Dedicated Gutenberg block + **shortcode** support
- Fully responsive; **poster** image support
- Playback: **Autoplay, Loop/Repeat, Reset on End, Start Muted, Auto-Hide Controls, Lazy Load**
- Control toggles: Play Large, Play, Restart, Rewind, Fast Forward, Progress Bar, Current Time, Duration, Volume, Mute, Fullscreen, PIP, AirPlay, Captions, Settings, Download
- Style: **Width** (px/em/%), **Aspect Ratio** (16:9, 4:3, 1:1, 9:16, 21:9, Auto), **Rounded Corners**, **Accent Color**
- Captions/subtitles via **.vtt** (self-hosted videos)

**Pro adds**
- Engines: **React Video Player, Video.js, Vidstack**
- Blocks: **Video Gallery, Playlist, Lightbox, Reels, Comparison, Testimonial Card, Transcript**
- **HLS (.m3u8) & DASH (.mpd)** streaming
- External sources: **Amazon S3, DigitalOcean Spaces, BunnyCDN**
- **Google Cast / Chromecast** + **priority support**

**Keep accurate on screen**
- Autoplay generally requires **muted** in modern browsers.
- **AirPlay** only shows in **Safari on macOS/iOS** for self-hosted videos.
- Captions apply to **self-hosted** videos; YouTube/Vimeo supply their own.
